# Office ERP System

A simple web-based Office ERP System for managing employees and daily office operations.

## Features

* Admin & Employee Login
* Role-Based Access Control
* Employee Management
* Attendance Management
* Leave Management
* Task Management
* Payroll Management
* Employee-specific Data Access
* Admin Dashboard
* Employee Dashboard
* Calendar

## User Roles

### Admin

* Manage employees
* Manage attendance
* Manage leaves
* Create and manage tasks
* Manage payroll
* View reports
* Access settings

### Employee

* View personal dashboard
* View own attendance
* Apply and view own leaves
* View and update assigned tasks
* View own payroll
* Access calendar

## Technologies Used

* HTML
* CSS
* JavaScript
* Node.js
* Express.js
* MongoDB
* Mongoose
